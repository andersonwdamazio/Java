## Getting Started

Objetivo Geral: 
Criar uma aplicação Java utilizando conceitos de herança para representar a hierarquia dos Arcossauros;

Objetivos Específicos:
Utilizar o princípio de Herança e Polimorfismo;
Exibir no console características de cada animal;
Exemplo: Saurísquios são um tipo de dinossauro, pode ser carnívoro como o Tiranossauro Rex;
